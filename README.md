# Demo_Algoritm_Varnakov

| Папка | Задание |
|---|---|
| `01_FunctionalLogic/1_Calculator` | Отработка ввода/вывода: два аргумента, результат сложения, вычитания, умножения, деления |
| `01_FunctionalLogic/2_NameList` | Список имён: добавление, удаление, Ctrl+Z, нормализация, проверка символов, дубликаты |
| `02_ApiClient/1_ApiOnly` | Клиент API TransferSimulator с выбором типа данных |
| `02_ApiClient/2_Full` | То же + авторизация с капчей-пазлом, регистрация, блокировка, администратор |
| `03_Checklist` | Чек-лист по документу «Требования к разработке» |

## Запуск

Открыть папку нужного проекта (где лежит `pom.xml`) в IntelliJ IDEA и запустить класс `app.Launcher`,
или из этой папки:

```
mvn javafx:run
```

В версии с капчей при первом запуске создаётся пользователь `admin` / `admin`.
